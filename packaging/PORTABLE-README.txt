Super Paste portable package

Windows: run super_paste.exe. Microsoft Edge WebView2 Runtime must be installed.
Linux: run Super-Paste.AppImage. The host system must provide FUSE 2 or a compatible AppImage runtime.

The portable copy uses the same isolated Super Paste data directory as its installed package. It does not read or migrate Electron data automatically. Run migrate-electron separately to migrate data while both applications are closed.
